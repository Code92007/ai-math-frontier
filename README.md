# 边界迁移

一个本地优先的中文里程碑档案，记录生成式 AI 对数学、物理、生物研究与算法竞赛的改变。

## 功能

- 数学界 / 算法界 / 算法竞赛界 / 物理界 / 生物界五领域时间线
- 按领域、事件类型和关键词筛选
- 每条事件保留证据等级、旧边界、新结果和原始来源
- 在浏览器中新增、编辑和删除里程碑
- 使用 IndexedDB 本地保存，无需后端
- JSON 导出与导入，便于备份和迁移
- 纯静态文件，可直接部署到 GitHub Pages

## 本地运行

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

也可以直接打开 `index.html`。通过本地服务器访问时，浏览器的数据权限行为通常更稳定。

## 数据说明

种子数据位于 `app.js` 的 `SEED_EVENTS`。首次访问时，数据会写入名为 `boundary-migration` 的 IndexedDB 数据库。此后在界面中的修改只保存在当前浏览器，不会修改仓库中的种子数据。

需要把本地补充同步到其他设备时，先使用“导出备份”，再在目标浏览器中导入 JSON。

事件的标签有意区分：

- `已核验 / 可机检`：存在外部检查、形式化验证或赛事监督
- `机构或作者发布`：已有一手发布，但不等于完成同行评议
- `社区整理 / 复现`：来自公开题解、讨论区或社区清单

## 部署

仓库包含 GitHub Pages 工作流。推送到 GitHub 后，在仓库 Settings → Pages 中将 Source 设为 `GitHub Actions`，后续推送会自动部署。
